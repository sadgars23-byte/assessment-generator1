# AI Assessment Generator

A React + TypeScript application built with TanStack Start.

## Requirements
- Node.js (current LTS)
- npm

## Run locally
```sh
npm install
npm run dev
```

## AI provider configuration
The assessment generation backend uses an OpenAI-compatible API. Configure `AI_API_KEY`, and optionally `AI_BASE_URL` and `AI_MODEL`, in your server environment. Keep API keys server-side; do not prefix them with `VITE_`.
